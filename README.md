# discord-plugins

Userplugins for [Equicord](https://github.com/Equicord/Equicord) and [Testcord](https://codeberg.org/Testcord/TestCord) by [visiuun](https://github.com/visiuun).

| Plugin | What it does |
|---|---|
| [NotificationSounds](notificationSounds) | Different notification sounds for DMs, group DMs, pings, reply pings, role pings, @everyone, @here, threads and more. Upload your own sounds or pick Discord's. |

## Install

Copy a plugin folder into `src/userplugins` in your Equicord/Testcord source, run `pnpm build` and restart Discord.
